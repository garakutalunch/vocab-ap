使い方 / How to use

1. カードの作成 / Creating Cards

「ユニット管理」からテキストを直接入力するか、txtファイルを読み込みます。
Enter text directly from "Manage Units" or load a .txt file.
フォーマットは以下の通りです。
(Format: Target・Pron・Meaning : Sentence | Translation)

apple・æpl・りんご : I ate an apple. | 私はりんごを食べた。
grape・・ぶどう : He likes grapes. | 彼はぶどうが好きだ。
※発音記号がない場合は間を空けます(・・) / Leave blank if no pronunciation (・・)

2. 表示モード / Display Mode

  • All Hidden: ターゲット単語を完全に隠します。
    Completely hide the target word.
  • Cloze: 例文中のターゲット単語部分を「___」にします。
    Replace the target word in the sentence with "___".
  • Hint: ターゲット単語の頭文字だけを表示します(例: a___)。
    Show only the first letter of the target word (e.g., a___).

3. 復習アルゴリズム / Spaced Repetition

答えを見た後、ボタンを選んで次回の復習タイミングを決定します。
Choose a button after seeing the answer to determine the next review time.
完全に覚えた単語は「Mastered」にすると出題されなくなります。
Words marked as "Mastered" will no longer appear.

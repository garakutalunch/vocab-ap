📖 Quick Start Guide

ENG: ANKI Ver.1.51

✅ Works fully offline! No internet needed.

📱 Add to Your Home Screen

  • iPhone: Open in Safari > Tap Share (↑) > "Add to Home Screen"
  • Android: Open in Chrome > Tap "⋮" > "Add to Home screen"

📝 Adding a Word List

  1. Tap "Open File .txt" on the main screen
  2. Choose a .txt file
  3. Enter a unit name and tap "Start"

Format:
word /phonetics/ (meaning) : example sentence | translation

🎮 How to Study

  • Guess the hidden target word, then tap "Show Answer".
  • Choose when to see the card again (Again, Hard, Good, Easy).
  • Tap "✓ Mastered" once you know a word perfectly (It will not appear again).

🔊 Language & Voice Settings

Select the appropriate language and gender from the "Voice" menu (Eng, JP, CN).

⚠️ Note for iPhone users: If the voice sounds unnatural, please download high-quality voices from Settings > Accessibility > Spoken Content > Voices.

💾 Backup

Tap "Export Backup" to save your data as a JSON file to prevent data loss when cache clears.

JPN: ANKI Ver.1.51

✅ オフラインOK！インターネット不要で使えます。

📱 ホーム画面に追加する方法

  • iPhone: Safariで開く > 共有ボタン（↑） > 「ホーム画面に追加」
  • Android: Chromeで開く > 右上の「⋮」 > 「ホーム画面に追加」

📝 単語リストの追加方法

  1. 「Open File .txt」をタップしファイルを選択
  2. ユニット名を入力して「Start」

※テキストエリアに直接コピペでもOKです。
フォーマット: word /発音/ (意味) : 例文 | 和訳

🎮 使い方

  • 「Show Answer」で答えを確認後、次の出題タイミングを4つのボタンから選びます。
  • 完全に覚えた単語は「✓ Mastered」を押すと以後出題されなくなります（「リスト管理」から解除可能）。

🔊 言語・音声設定

学習する言語と性別を「音声 / Voice」から選んでください（英語 / 日本語 / 中国語）。学習言語と違う音声を選ぶと不自然になります。

⚠️ iPhoneで目的の声が出ない場合：「設定 ＞ アクセシビリティ ＞ 読み上げコンテンツ ＞ 声」から音声をダウンロードしてください。

💾 バックアップ

「Export Backup」でデータをJSON保存できます。ブラウザ履歴消去に備えて定期的にバックアップしてください。
